# Simple Calculator Using Python

A basic command-line calculator developed using Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Invalid input handling

## Technologies Used

- Python

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run:

```bash
python calculator.py
